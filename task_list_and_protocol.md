# Task List and Measurement Protocol

**Project:** CAPSTONE 42 — AI Time-Audit: Before and After Productivity Study  
**Research question:** How much time can AI save across common student or office tasks?

## Selected tasks
1. Summarising lecture notes
2. Drafting a formal email
3. Planning a weekly schedule
4. Comparing research sources
5. Creating spreadsheet formulas
6. Creating a presentation outline

## Timing protocol
- Use the same task brief and input materials for the manual and AI-assisted attempts.
- Start the timer when work begins and stop when a usable first draft/output is ready.
- Include prompt writing, reading the AI response, corrections, and verification in AI-assisted time.
- Record minutes to the nearest whole minute; do not exclude failed attempts or rework.
- Keep task difficulty and completion criteria as consistent as possible.
- For a fair comparison, avoid using the manual output as hidden input for the AI attempt (or vice versa).
- Ask a reviewer who does not know which method produced the output to score quality, if feasible.

## Formulae
- Minutes saved = manual minutes − AI-assisted minutes
- Time saved (%) = (minutes saved ÷ manual minutes) × 100
- Quality difference = AI quality score − manual quality score

## Important data note
The included numbers are **illustrative demo values**, created to show the complete workflow and deliverable format. They are not measured results. Replace them with your own timed observations before presenting this as an empirical study.
