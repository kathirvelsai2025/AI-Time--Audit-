# AI Time-Audit: Before and After Productivity Study

This ZIP contains a complete starter pack for the CAPSTONE 42 project.

## Start here
1. Read `documentation/task_list_and_protocol.md`.
2. Replace the example values in `data/time_and_quality_data.csv` with your measured observations.
3. Keep task names consistent and update the separate CSV exports if you edit the combined dataset.
4. Run `demo/demo.py` to calculate and plot the results (requires Python, pandas, matplotlib).
5. Update charts, report, and presentation using your real results.
6. Use `prompts/prompt_library.md` to standardise prompts.
7. Review `reports/verification_report.md` before final submission.

## Contents
- Task list and measurement protocol
- Time data, quality scores, and combined dataset (CSV)
- Three charts (PNG)
- 6-slide PowerPoint presentation
- Prompt library
- Before/after analysis
- Verification and responsible-AI report
- Python analysis demo
- Final demo walkthrough
- PDF report summary

## Critical data integrity note
The included numbers are **illustrative demo values** to demonstrate the workflow and visualisation. They are not real observations and must not be presented as results from a completed experiment. Conduct and document your own timed runs and quality scoring before final submission.
