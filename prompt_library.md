# Prompt Library — AI Time-Audit

Use these prompts as starting points. Replace bracketed fields with your own materials. Record the exact prompt version used for each timed run.

## 1. Summarising lecture notes
> Summarise the notes below for a student revising for an exam. Organise the result into: (1) key concepts, (2) definitions, (3) important examples, and (4) five self-test questions. Do not add facts that are not supported by the notes. Flag unclear or missing information. Notes: [paste notes]

## 2. Drafting a formal email
> Draft a concise, respectful email to [recipient/role] about [purpose]. Include the necessary context, a clear request, and a polite closing. Do not invent dates, promises, or personal details. Keep it under [word count] words. Context: [details]

## 3. Planning a weekly schedule
> Build a realistic weekly schedule using these fixed commitments: [commitments]. Priorities: [tasks]. Add reasonable breaks and travel time. Identify conflicts and assumptions instead of silently inventing solutions. Return a table with day, time, activity, and priority.

## 4. Comparing research sources
> Compare the following sources for relevance to [research question]. For each, list the main claim, evidence used, date, limitations, and what needs independent verification. Do not treat unsupported statements as facts. Sources: [links or excerpts]. End with a balanced comparison, not a forced conclusion.

## 5. Creating spreadsheet formulas
> I am using [Excel/Google Sheets]. Columns and sample rows: [schema/sample]. I need a formula to calculate [desired result]. Give the formula, explain each part, state assumptions about blank cells and data types, and test it against these examples: [expected inputs/outputs]. Do not claim it works until the test cases are checked.

## 6. Creating a presentation outline
> Create a [5–7]-slide presentation for [audience] about [topic]. Include a clear story: problem, method, results, limitations, recommendations, conclusion. Use concise slide bullets and suggest one appropriate chart. Mark any placeholder or unverified claim clearly. Source material: [material].

## 7. Verification prompt (use after any AI response)
> Audit the response above. List every factual claim, calculation, source-dependent statement, and assumption. For each, label it as verified from supplied evidence, independently verified, unverified, or opinion. Recalculate numeric results and identify omissions or possible hallucinations. Do not defend the answer just because you generated it.

## 8. Reflection prompt: when AI made work worse
> Review this AI-assisted output against the task brief and rubric: [brief, output, rubric]. Identify errors, generic content, missing context, bias, privacy concerns, and time spent correcting it. State whether AI was genuinely helpful after accounting for verification and rework.
